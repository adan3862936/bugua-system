# 濟公象棋卜卦系統

個人學習用工具。包含五個主要功能：

- **單卦（5 子）**：自動偵測 22 種格局、計算分數、生成解盤敘述
- **命盤（32 子）**：自動拆 8 局、跨局財富分析、大限警示
- **前世因果**：前世性別／身分／關係判讀
- **生命靈數**：生日數字、後天五行與九星五行分析
- **速查表**：14 棋子＋格局＋起卦流程＋顯化淨化 SOP

## 使用

雙擊 `index.html` 或直接開瀏覽器訪問此頁。本機 `file://`/localhost 模式可免登入使用。

純前端，離線可用。
